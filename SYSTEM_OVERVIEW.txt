🎯 TWO MAIN FEATURES IMPLEMENTED
================================================================================

FEATURE 1: MOE DATA SYNCHRONIZATION
────────────────────────────────────
Endpoint:  POST /api/admin/moe-sync
Purpose:   Import and manage student data from Ministry of Education
Input:     CSV or JSON file + version identifier
Output:    Sync summary with statistics (added/updated/unchanged/deactivated)

Key Features:
  ✓ Parse CSV and JSON files
  ✓ Validate all required fields
  ✓ Update existing records if changed
  ✓ Create new student records
  ✓ Mark unchanged records
  ✓ Deactivate students not in new file
  ✓ Prevent duplicate version imports
  ✓ Complete audit trail logging
  ✓ Detailed error reporting per row

Sample Response:
  {
    "success": true,
    "message": "MOE data synchronized successfully",
    "summary": {
      "totalRecords": 5,
      "addedRecords": 5,
      "updatedRecords": 0,
      "unchangedRecords": 0,
      "deactivatedRecords": 0
    }
  }

FEATURE 2: STUDENT AUTHENTICATION
──────────────────────────────────
Endpoint:  POST /api/auth/login
Purpose:   Authenticate students against MOE verified database
Input:     examID (string) + dateOfBirth (YYYY-MM-DD)
Output:    Student data if successful, error if failed

Key Features:
  ✓ Two-field verification (dual factor)
  ✓ Database lookup by exam ID
  ✓ Date of birth validation
  ✓ Active/inactive status checking
  ✓ Secure credential comparison
  ✓ Proper error responses (401, 403, etc.)
  ✓ No sensitive data leakage

Sample Request:
  {
    "examID": "EXM-2024-001",
    "dateOfBirth": "2004-05-15"
  }

Sample Success Response:
  {
    "success": true,
    "data": {
      "studentId": 1,
      "examID": "EXM-2024-001",
      "firstName": "Abebe",
      "lastName": "Kebede",
      "email": "abebe.kebede@example.com",
      "phone": "+251911222333",
      "region": "Addis Ababa",
      "dateOfBirth": "2004-05-15"
    }
  }
